🌐 Fetch API - Primera Petición

¿Qué es Fetch?

Herramienta de JavaScript para hacer peticiones HTTP a servidores y APIs

Sintaxis Básica:

// Con .then()
fetch('url')
    .then(response => response.json())
    .then(data => console.log(data));

// Con async/await (RECOMENDADO)
const response = await fetch('url');
const data = await response.json();
