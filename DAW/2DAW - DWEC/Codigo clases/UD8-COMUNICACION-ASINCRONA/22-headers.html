📋 Headers en Fetch

¿Qué son los Headers?

Los headers son metadatos que acompañan a las peticiones HTTP. Le dicen al servidor información adicional sobre la petición.

Content-Type

¿Qué envío?

application/json

Indica que estamos enviando datos en formato JSON

Accept

¿Qué espero recibir?

application/json

Indica que queremos recibir JSON como respuesta

Authorization

¿Quién soy?

Bearer token123

Token de autenticación (veremos más adelante)

🎯 Ejercicio 2: Crear usuario con headers

Vamos a crear un usuario nuevo enviando headers completos.

Endpoint: https://jsonplaceholder.typicode.com/users

Headers necesarios:

  • Content-Type: application/json
  • Accept: application/json

Abre la consola (F12) para ver el status y headers de respuesta.

Ejemplo de headers:

headers: {
    'Content-Type': 'application/json',
    'Accept': 'application/json'
}

Tipos de Content-Type comunes:

Content-Type Uso
application/json Datos JSON (el más común)
application/x-www-form-urlencoded Formularios HTML tradicionales
multipart/form-data Subida de archivos
text/plain Texto simple
