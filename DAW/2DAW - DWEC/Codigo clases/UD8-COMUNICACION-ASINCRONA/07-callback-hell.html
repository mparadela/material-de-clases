🔥 Callback Hell (Pirámide del Infierno)

El Problema:

Cuando necesitamos hacer varias operaciones asíncronas en cadena, los callbacks se anidan y forman una pirámide difícil de leer y mantener.

operacion1(() => {
    operacion2(() => {
        operacion3(() => {
            operacion4(() => {
                // ← Cada vez más a la derecha
            });
        });
    });
});
