📋 Headers Avanzados en Fetch

¿Qué son los Headers?

Los headers son metadatos que viajan con las peticiones y respuestas HTTP.

Permiten enviar información adicional al servidor y recibir información de vuelta.

🎯 Headers más comunes

📤 Headers de PETICIÓN (Request)

Content-Type

¿Qué envío?

application/json

Tipo de datos que estoy enviando al servidor

Accept

¿Qué quiero recibir?

application/json

Tipo de datos que espero en la respuesta

Authorization

¿Quién soy?

Bearer token123...

Token de autenticación para identificarme

User-Agent

¿Desde dónde accedo?

MiApp/1.0

Identifica navegador/aplicación

📥 Headers de RESPUESTA (Response)

Content-Type

¿Qué me envían?

application/json

Tipo de datos en la respuesta

Date

¿Cuándo?

Thu, 13 Feb 2025...

Fecha y hora de la respuesta

Server

¿Qué servidor?

nginx/1.20.0

Software del servidor

Cache-Control

¿Cachear?

no-cache

Política de caché

✨ Headers Personalizados

Puedes crear tus propios headers. Por convención, empiezan con X-

X-API-Key: abc123...

Clave de API personalizada

X-Request-ID: uuid-123

ID único para rastrear petición

X-Custom-Header: valor

Cualquier dato que necesites

🎯 Ejercicio 9: Headers personalizados

Vamos a hacer una petición con múltiples headers personalizados y analizar los headers de respuesta.

API: https://jsonplaceholder.typicode.com/posts/1

Vamos a:

  1. Crear petición GET con headers personalizados
  2. Añadir: Accept, User-Agent, X-API-Key, X-Custom-Header
  3. Analizar los headers de respuesta
  4. Iterar todos los headers con forEach

Abre la consola (F12) y también la pestaña Network para ver los headers.

Cómo acceder a headers de respuesta:

// Un header específico
response.headers.get('content-type')

// Iterar todos los headers
response.headers.forEach((valor, nombre) => {
    console.log(nombre + ': ' + valor);
})
💡 Nota: Los headers son case-insensitive (mayúsculas/minúsculas no importan). 'Content-Type' = 'content-type'
