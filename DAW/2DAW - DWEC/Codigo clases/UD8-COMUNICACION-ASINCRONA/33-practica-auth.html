🎯 Práctica: Fetch Autenticado con Reintentos

Ejercicio Integrador

Vamos a crear una función que combine TODO lo aprendido:

  • ✅ Autenticación con Bearer Token
  • ✅ Reintentos automáticos si falla
  • ✅ Manejo de errores completo
  • ✅ Verificación de token válido

📋 Requisitos de la función

🔑

1. Obtener token de localStorage

Si no hay token → Error inmediato

🔄

2. Intentar hasta 3 veces

Si falla → Esperar y reintentar

📤

3. Header Authorization

Enviar token en cada intento

⚠️

4. Verificar status 401

Si 401 → Token inválido, no reintentar

✅

5. Devolver datos

Si éxito → Devolver respuesta JSON

📝

6. Logs informativos

Console.log de cada paso

🎯 Firma de la función

async function fetchAutenticado(url, intentosMaximos = 3) {
    // Tu código aquí
    // Debe devolver los datos o null si falla
}

📊 Flujo de la función

1

Obtener token

localStorage.getItem('auth_token')
✅ Hay token → Continuar
❌ No hay token → return null
2

Bucle de reintentos

for (let i = 1; i <= intentosMaximos; i++)
3

Hacer fetch con token

headers: { 'Authorization': `Bearer ${token}` }
4

Verificar respuesta

✅ response.ok → Devolver datos
❌ Status 401 → Token inválido, return null
❌ Otro error → Reintentar
5

Si falla y no es 401

await new Promise(r => setTimeout(r, i * 1000))

Esperar más tiempo en cada intento

6

Si agotan reintentos

return null

🎯 Ejercicio 14: Implementar la función

API: https://jsonplaceholder.typicode.com/posts/1

Pasos:

  1. Simular guardado de token: localStorage.setItem('auth_token', 'abc123')
  2. Implementar función fetchAutenticado(url, intentosMaximos)
  3. Comprobar que obtiene el token correctamente
  4. Hacer fetch con header Authorization
  5. Implementar lógica de reintentos con backoff
  6. Manejar casos especiales: 401, errores de red
  7. Probar la función llamándola

Abre la consola (F12) para ver todo el proceso paso a paso.

🧪 Casos de prueba

Caso 1: Token válido

→ Debe funcionar en el primer intento

Caso 2: Sin token

→ Debe devolver error inmediato

Caso 3: Token inválido (simular)

→ Debe detectar 401 y no reintentar

💡 Pistas de código

Verificar si es error 401:

if (response.status === 401) {
    console.log("Token inválido");
    localStorage.removeItem('auth_token');
    return null;
}

Esperar antes de reintentar:

// Espera 1s, 2s, 3s según el intento
const espera = intento * 1000;
await new Promise(resolve => setTimeout(resolve, espera));

Verificar último intento:

if (intento === intentosMaximos) {
    console.log("Todos los intentos fallaron");
    return null;
}
