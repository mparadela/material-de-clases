📖 Guía: Documentación de PokeAPI

¿Qué es PokeAPI?

PokeAPI es una API REST pública y gratuita con información completa sobre Pokémon.

🌐 Web: https://pokeapi.co

📚 Documentación: https://pokeapi.co/docs/v2

🎯 Paso 1: Entender la URL base

Todas las peticiones empiezan con:

https://pokeapi.co/api/v2/

A esta URL base le añades el endpoint que quieras consultar.

📋 Paso 2: Endpoints principales

Endpoint ¿Qué devuelve? Ejemplo
/pokemon Lista de todos los pokémon (paginada) Ver
/pokemon/{id} Datos de un pokémon específico por ID Ver (Pikachu)
/pokemon/{nombre} Datos de un pokémon específico por nombre Ver
/type Lista de tipos (fire, water, etc) Ver
/ability Lista de habilidades Ver

🔍 Paso 3: Probar un endpoint en el navegador

Ejemplo: Vamos a obtener datos de Pikachu

  1. Abre una pestaña nueva en el navegador
  2. Escribe en la barra de direcciones: https://pokeapi.co/api/v2/pokemon/pikachu
  3. Pulsa Enter
  4. Verás un JSON enorme con todos los datos de Pikachu

💡 Truco: Instala la extensión JSON Viewer para ver el JSON más bonito y con colores.

📊 Paso 4: Entender la estructura del JSON

Cuando pides un pokémon, recibes un objeto JSON con esta estructura:

{
  "id": 25,
  "name": "pikachu",
  "height": 4,
  "weight": 60,
  "sprites": {
    "front_default": "https://...",
    "back_default": "https://...",
    ...
  },
  "types": [
    {
      "slot": 1,
      "type": {
        "name": "electric",
        "url": "https://..."
      }
    }
  ],
  "stats": [
    {
      "base_stat": 35,
      "stat": {
        "name": "hp"
      }
    },
    ...
  ],
  "abilities": [...],
  "moves": [...]
}

🎯 Paso 5: Extraer los datos que necesitas

No necesitas usar TODO el JSON. Extrae solo lo que necesites:

Campo Cómo acceder Ejemplo
Nombre pokemon.name "pikachu"
ID pokemon.id 25
Imagen frontal pokemon.sprites.front_default "https://..."
Tipo(s) pokemon.types[0].type.name "electric"
HP (vida) pokemon.stats[0].base_stat 35
Ataque pokemon.stats[1].base_stat 55
Defensa pokemon.stats[2].base_stat 40

🎯 Ejercicio práctico: Código en JavaScript

Así es como obtendrías y mostrarías los datos en JavaScript:

Ejemplo completo:

// Función para buscar un pokémon
async function buscarPokemon(nombre) {
    // URL del endpoint
    const url = `https://pokeapi.co/api/v2/pokemon/${nombre}`;
    
    try {
        // Hacer petición
        const response = await fetch(url);
        
        // Verificar que existe
        if (!response.ok) {
            console.log("Pokemon no encontrado");
            return;
        }
        
        // Convertir a JSON
        const pokemon = await response.json();
        
        // Extraer datos que necesito
        const nombre = pokemon.name;
        const id = pokemon.id;
        const imagen = pokemon.sprites.front_default;
        const tipo = pokemon.types[0].type.name;
        const hp = pokemon.stats[0].base_stat;
        const ataque = pokemon.stats[1].base_stat;
        
        // Mostrar en consola
        console.log(`${nombre.toUpperCase()} (#${id})`);
        console.log(`Tipo: ${tipo}`);
        console.log(`HP: ${hp} | Ataque: ${ataque}`);
        console.log(`Imagen: ${imagen}`);
        
    } catch (error) {
        console.log("Error:", error.message);
    }
}

// Probar con Pikachu
buscarPokemon("pikachu");

Prueba tú:

  1. Copia este código en tu consola del navegador (F12)
  2. Ejecuta: buscarPokemon("pikachu")
  3. Prueba con otros: buscarPokemon("charizard")
  4. Prueba con IDs: buscarPokemon("1") → Bulbasaur

💡 Consejos útiles

✅ Buenas prácticas

  • Siempre usa toLowerCase() para nombres
  • Verifica response.ok antes de parsear
  • Usa try/catch para errores de red
  • Los IDs van del 1 al 1025
  • La API es lenta a veces, ten paciencia

❌ Errores comunes

  • Escribir mal el nombre (mayúsculas)
  • No verificar si el pokémon existe
  • Olvidar await en fetch
  • No manejar el error 404
  • Acceder a arrays sin verificar longitud
