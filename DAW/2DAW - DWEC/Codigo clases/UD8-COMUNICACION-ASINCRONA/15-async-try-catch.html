🛡️ Manejo de Errores: try/catch

Patrón Estándar:

async function miFuncion() {
    try {
        // Intentar operación
        const resultado = await operacionAsincrona();
        console.log(resultado);
        
    } catch (error) {
        // Capturar error
        console.error("Error:", error);
        
    } finally {
        // Limpieza (siempre se ejecuta)
        console.log("Operación terminada");
    }
}

try

Intenta ejecutar el código

catch

Captura errores si algo falla

finally

Se ejecuta siempre (opcional)
