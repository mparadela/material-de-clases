🗑️ DELETE: Eliminar Recurso

¿Qué es DELETE?

DELETE elimina un recurso del servidor de forma permanente.

⚠️ Acción irreversible: Siempre pedir confirmación al usuario.

Características de DELETE

🎯

Requiere ID

URL con ID específico

/posts/1

📭

Sin body

No envía datos

No body needed

✅

Status 204 o 200

No Content o OK

204 / 200

⚠️

Irreversible

Pedir confirmación

confirm()

📋 Patrón DELETE Profesional

  1. Obtener recurso: Mostrar qué se va a eliminar
  2. Pedir confirmación: confirm() con información del recurso
  3. DELETE solo si confirma: Enviar petición DELETE
  4. Actualizar UI: Quitar de la lista en pantalla

🎯 Ejercicio 7: Eliminar post con confirmación

Vamos a eliminar el post 1, pero SIEMPRE pidiendo confirmación mostrando el título.

Endpoint: https://jsonplaceholder.typicode.com/posts/1

Vamos a programar:

  1. Función que obtiene el post para mostrar su título
  2. Pedir confirmación con confirm()
  3. Si acepta → DELETE
  4. Si cancela → No hacer nada
  5. Verificar response.status (204 o 200)

Abre la consola (F12) para ver el proceso completo.

Estructura DELETE:

fetch(`/posts/${id}`, {
    method: 'DELETE'
})

// No lleva headers ni body
// Solo URL + method

📊 Respuestas comunes de DELETE

Status Significado Acción
204 No Content ✅ Eliminado (sin respuesta)
200 OK ✅ Eliminado (con confirmación)
404 Not Found ❌ Ya estaba eliminado o ID incorrecto
403 Forbidden ❌ Sin permisos para eliminar

⚠️ IMPORTANTE: Confirmación siempre

Nunca elimines sin pedir confirmación. Es mala UX y puede causar pérdida de datos accidental.
