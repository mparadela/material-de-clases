✏️ PUT: Actualizar Recurso Completo

¿Qué es PUT?

PUT se usa para actualizar un recurso completo que ya existe en el servidor.

Tienes que enviar TODOS los campos del recurso, aunque no cambien todos.

POST

➕

Crear nuevo

  • Crea un recurso
  • No necesita ID
  • URL: /posts

PUT

✏️

Actualizar existente

  • Actualiza recurso
  • Necesita ID
  • URL: /posts/1

🎯 Patrón PUT en 3 pasos

1. GET

Obtener recurso actual

fetch('/posts/1')

2. Modificar

Cambiar los campos necesarios

post.title = "Nuevo"

3. PUT

Enviar recurso completo

method: 'PUT'

🎯 Ejercicio 5: Actualizar un post

Vamos a actualizar el post con ID 1. Primero lo obtenemos, luego modificamos el título y contenido, y finalmente lo enviamos con PUT.

API: https://jsonplaceholder.typicode.com/posts/1

Pasos a programar:

  1. GET para obtener post original
  2. Copiar todo con spread operator (...)
  3. Modificar solo title y body
  4. PUT para actualizar
  5. Verificar response.status === 200

Abre la consola (F12) para ver el antes y después.

Estructura PUT:

fetch(`/posts/${id}`, {
    method: 'PUT',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify(objetoCompleto)
})
💡 Recuerda: La URL lleva el ID del recurso: /posts/1, /users/5, etc.
