🔗 .then(), .catch(), .finally()

.then()

Se ejecuta cuando la promesa se cumple (FULFILLED)

promesa.then(resultado => { ... })

.catch()

Se ejecuta cuando la promesa se rechaza (REJECTED)

promesa.catch(error => { ... })

.finally()

Se ejecuta SIEMPRE, haya éxito o error

promesa.finally(() => { ... })
