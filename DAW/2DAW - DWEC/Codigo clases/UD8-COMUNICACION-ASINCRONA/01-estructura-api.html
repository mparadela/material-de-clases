📡 Estructura típica de respuestas de API

💡 Abre la consola (F12) para ver análisis detallado

1️⃣ Objeto único (UN usuario, UN producto, UN post)

Cuándo se usa: Al pedir un recurso específico por ID

Ejemplo: GET /users/1, GET /posts/5


        

            Acceso directo a propiedades: usuario.name, usuario.email
        

    


    

        
2️⃣ Array de objetos (LISTA de usuarios, productos, posts)

        
Cuándo se usa: Al pedir múltiples recursos

        
Ejemplo: GET /posts, GET /users

        

        

            Hay que recorrer con: .forEach(), .map(), .filter()
        

    


    

        
3️⃣ Objeto con metadatos (información + datos)

        
Cuándo se usa: APIs más complejas con paginación

        
Incluye: Estado, mensaje, paginación, datos

        

        

            Los datos reales están en: respuesta.data o respuesta.results
