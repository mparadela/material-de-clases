🎯 Ejercicio 8: Panel CRUD interactivo

Vamos a programar los 4 botones para hacer las operaciones CRUD sobre posts.

API: https://jsonplaceholder.typicode.com/posts

Funcionalidades a programar:

  • Listar: GET primeros 5 posts y mostrar sus títulos
  • Crear: POST un post nuevo con título y contenido fijos
  • Actualizar: PUT para actualizar el post 1
  • Eliminar: DELETE el post 1

Cada botón debe mostrar el resultado en la sección inferior con formato bonito.

Abre la consola (F12) para ver los logs de cada operación.

📝 Resumen de métodos HTTP

Método Acción URL Body Status
GET Leer /posts ❌ No 200
POST Crear /posts ✅ Sí 201
PUT Actualizar todo /posts/1 ✅ Sí 200
PATCH Actualizar parcial /posts/1 ✅ Sí 200
DELETE Eliminar /posts/1 ❌ No 204
