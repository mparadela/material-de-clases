📊 Analizar Respuesta del POST

Información de la Respuesta

Cuando hacemos un POST, el servidor nos devuelve información útil que debemos analizar.

Status Code

201

Created

Indica que el recurso se creó correctamente

Status Text

OK

Descripción textual

Texto que acompaña al código numérico

response.ok

true

Booleano

true si status 200-299, false en otro caso

📋 Códigos HTTP en POST

✅ Éxito (2xx)

  • 200 OK - Operación exitosa
  • 201 Created - Recurso creado (el más común en POST)
  • 204 No Content - Éxito sin contenido en respuesta

⚠️ Error del Cliente (4xx)

  • 400 Bad Request - Datos mal formados
  • 401 Unauthorized - No autenticado
  • 403 Forbidden - Sin permisos
  • 404 Not Found - Endpoint no existe
  • 422 Unprocessable Entity - Validación falló

❌ Error del Servidor (5xx)

  • 500 Internal Server Error - Error interno del servidor
  • 502 Bad Gateway - Gateway inválido
  • 503 Service Unavailable - Servicio no disponible

🎯 Ejercicio 4: Analizar respuesta completa

Vamos a crear un post y analizar toda la información que nos devuelve el servidor.

Vamos a mostrar:

  • Status code y status text
  • Headers de respuesta (Content-Type, Date)
  • Body con los datos del post creado
  • Verificación de response.ok

Abre la consola (F12) para ver todo el análisis.

💡 Buena práctica: Siempre verifica response.ok antes de procesar los datos.
