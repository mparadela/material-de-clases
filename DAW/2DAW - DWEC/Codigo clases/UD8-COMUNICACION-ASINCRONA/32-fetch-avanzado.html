⚡ Fetch Avanzado: Timeout y Reintentos

Problemas en el mundo real

Las APIs no siempre responden rápido o de forma fiable:

  • 🐌 API lenta → Necesitas timeout
  • 💥 Error temporal → Necesitas reintentos
  • 📶 Conexión inestable → Necesitas estrategia de respaldo

⏰ Timeout: Límite de tiempo

❌ Problema

Fetch no tiene timeout nativo.

Si la API tarda mucho, tu app se queda esperando indefinidamente.

✅ Solución

Usar AbortController para cancelar la petición después de X segundos.

🎮 AbortController

1

Crear controller

new AbortController()
2

Obtener signal

controller.signal
3

Pasar a fetch

fetch(url, { signal })
4

Abortar si tarda

controller.abort()

📈 Exponential Backoff

Esperar más tiempo entre cada intento:

Intento 1: 1 segundo
Intento 2: 2 segundos
Intento 3: 4 segundos
Intento 4: 8 segundos

💡 Esto evita saturar el servidor con peticiones rápidas.

🎯 Ejercicio 12: Fetch con timeout

Vamos a implementar una función que cancela la petición si tarda más de 5 segundos.

API: https://jsonplaceholder.typicode.com/posts/1

Vamos a programar:

  1. Función fetchConTimeout(url, timeout)
  2. Crear AbortController y signal
  3. setTimeout que llama a abort() después de X ms
  4. Pasar signal al fetch
  5. Capturar error AbortError si se cancela
  6. clearTimeout si llega a tiempo

Abre la consola (F12) para ver si se cancela o no.

🎯 Ejercicio 13: Fetch con reintentos

Vamos a implementar una función que reintenta automáticamente si falla.

API: https://jsonplaceholder.typicode.com/posts/1

Vamos a programar:

  1. Función fetchConReintentos(url, intentosMaximos)
  2. Bucle for que intenta hasta N veces
  3. Si falla, esperar un poco (backoff)
  4. Si es el último intento, lanzar error
  5. Si tiene éxito, devolver datos
  6. Logs de cada intento en consola

Abre la consola (F12) para ver los intentos.

🎯 Patrones profesionales

⏰ Timeout

Para APIs lentas o poco confiables

fetchConTimeout(url, 5000)

🔄 Reintentos

Para errores temporales (500, red)

fetchConReintentos(url, 3)

💾 Caché

Guardar respuesta en localStorage

localStorage.setItem(url, data)

🔄 Polling

Actualizar cada X segundos

setInterval(fetch, 10000)
💡 En producción: Usa librerías como axios o ky que ya tienen timeout y reintentos incluidos.
