📋 Headers HTTP Básicos

¿Qué son los Headers?

Los headers son metadatos que viajan con las peticiones y respuestas HTTP.

Permiten enviar información adicional al servidor y recibir información de vuelta.

📤 Headers de Petición

  • Content-Type: Tipo de datos que envío
  • Accept: Tipo de datos que espero
  • Authorization: Token de autenticación
  • User-Agent: Navegador/App que hace la petición

📥 Headers de Respuesta

  • Content-Type: Tipo de datos enviados
  • Date: Fecha y hora del servidor
  • Server: Software del servidor
  • Cache-Control: Política de caché
