📝 Formulario con POST

Caso práctico más común

Lo más habitual es enviar datos de un formulario HTML a una API usando POST.

Patrón: Usuario rellena → JavaScript recoge datos → POST a API → Mostrar resultado

🎯 Pasos que vamos a programar:

  1. preventDefault() → Evitar que recargue la página
  2. Recoger valores → Del formulario con .value
  3. Crear objeto → Con los datos del formulario
  4. Mostrar loading → Feedback mientras envía
  5. fetch POST → Enviar datos a la API
  6. Verificar respuesta → Comprobar que salió bien
  7. Mostrar resultado → En la sección de resultado
  8. Limpiar formulario → Con reset()
⚠️ MUY IMPORTANTE: Sin preventDefault(), el formulario recarga la página y pierdes todo.
