📤 Fetch POST Básico

¿Qué es POST?

POST se usa para enviar datos al servidor y crear nuevos recursos.

GET (lo que ya sabemos)

  • Solo LEER datos
  • No envía body
  • Sintaxis simple
  • Solo URL
fetch(url)

POST (nuevo)

  • ENVIAR datos
  • Requiere body
  • Requiere headers
  • Objeto de configuración
fetch(url, opciones)

🎯 Ejercicio 1: Comparar GET vs POST

Vamos a hacer una petición GET y una POST a la misma API para ver la diferencia.

API: https://jsonplaceholder.typicode.com/posts

Abre la consola (F12) para ver los resultados.

Estructura POST:

fetch(url, {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify(objeto)
})
💡 Recuerda: El body debe ser un STRING, por eso usamos JSON.stringify()
